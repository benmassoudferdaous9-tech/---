قرطاج: مغامرة فردوس وندى عبر الزمن
==================================
التشغيل: افتح index.html في أي متصفح حديث (Chrome / Safari / Edge / Firefox).
الملف واحد مكتفٍ بذاته: الصور مدمجة داخله، والصوت مولَّد بـ Web Audio.
(خط Cairo يُحمَّل من الإنترنت إن توفر، وإلا يُستخدم Tahoma.)

الاستضافة: ارفع index.html إلى أي استضافة ثابتة (GitHub Pages / Netlify ...).
للهاتف: العب بوضع أفقي. على iPhone استخدم مشاركة > إضافة إلى الشاشة الرئيسية.

تعديل الأسئلة: ابحث في index.html عن المصفوفة Q.
